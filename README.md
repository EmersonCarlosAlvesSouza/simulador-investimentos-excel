# 📊 Simulador de Investimentos em Fundos Imobiliários (FIIs)

Este projeto consiste no desenvolvimento de uma ferramenta prática e automatizada no Microsoft Excel para a simulação de investimentos em Fundos Imobiliários (FIIs), criada como desafio prático na plataforma DIO (Digital Innovation One).

## 🚀 Objetivos do Projeto
- Auxiliar investidores iniciantes na tomada de decisões com base em dados.
- Automatizar cálculos financeiros complexos (Patrimônio acumulado, dividendos mensais e projeção de juros compostos).
- Aplicar conceitos avançados de fórmulas, formatação condicional e validação de dados no Excel.

## 🛠️ Recursos Utilizados no Excel
- **Validação de Dados:** Criação de listas suspensas para restringir entradas incorretas e garantir a integridade das fórmulas.
- **Formatação Condicional:** Destaque visual dinâmico de metas de rendimento e faixas de valores.
- **Fórmulas Avançadas:** Utilização de funções financeiras e lógicas para projeção de dividendos ao longo do tempo.
- **Tabelas Dinâmicas:** Estruturação de resumos gerenciais para análise rápida de cenários de aportes.

## 📁 Como Utilizar
1. Baixe o arquivo `.xlsx` presente neste repositório.
2. Abra no Microsoft Excel ou Google Planilhas.
3. Insira o valor do seu aporte inicial, aporte mensal e a taxa estimada de dividendos.
4. Analise os gráficos e tabelas de projeção de patrimônio gerados automaticamente.
